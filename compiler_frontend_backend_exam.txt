COMPILER DESIGN LAB — COMPLETE ANSWER (METHOD 1: SIMPLE EXAM METHOD)
=====================================================================

QUESTION
--------
Develop a front end of a compiler by generating intermediate code in the form of
three-address code (TAC) for the sample program using looping and assignment
statements. Optimize the generated intermediate code using code motion. Develop
a back end for an assignment statement.

INPUT PROGRAM
-------------
while (m < n * 4)
{
    r = 16 * 5;
    s = x * y + z;
    t = m + s;
}

IMPORTANT
---------
This answer uses a simple, multi-file implementation. The compiler generates
TAC from the input; optimizer.c reads that generated TAC and writes optimized
TAC; codegen.c reads the optimized TAC and produces assembly-like target code.
The target code is educational pseudo-assembly, not machine-specific assembly.

FOLDER SETUP
------------
Create a folder named:
    compiler_lab

Save all six files listed below inside that same folder:
    lex.l
    parser.y
    optimizer.c
    codegen.c
    input.txt
    (the generated files tac.txt, optimized.txt, target.txt will appear after running)

PART (a) — LEX SPECIFICATION TO IDENTIFY TOKENS
==============================================

FILE NAME: lex.l
SAVE LOCATION: compiler_lab/lex.l

CODE
----
%option noyywrap

%{
#include "parser.tab.h"
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
%}

%%
"while"                 { return WHILE; }
[0-9]+                  { yylval.str = strdup(yytext); return NUMBER; }
[a-zA-Z_][a-zA-Z0-9_]*  { yylval.str = strdup(yytext); return ID; }

"<"                     { return LT; }
"="                     { return ASSIGN; }
"+"                     { return PLUS; }
"-"                     { return MINUS; }
"*"                     { return MUL; }
"/"                     { return DIV; }

"("                     { return '('; }
")"                     { return ')'; }
"{"                     { return '{'; }
"}"                     { return '}'; }
";"                     { return ';'; }

[ \t\r\n]+              ;
.                       { fprintf(stderr, "Invalid character: %s\n", yytext); }
%%

EXPLANATION
-----------
LEX reads the source program and recognizes tokens.
- "while" is returned as WHILE.
- [0-9]+ recognizes integer numbers such as 4 and 16.
- [a-zA-Z_][a-zA-Z0-9_]* recognizes identifiers such as m, total, and x1.
- Operators such as <, =, +, -, *, / are recognized.
- Parentheses, braces, and semicolons are returned as character tokens.
- Spaces and newlines are ignored.
- Any unrecognized character is reported as invalid.

LEX does not check the complete grammar. It sends tokens to YACC/Bison.

PART (b) AND (c) — YACC SYNTAX CHECKING AND TAC GENERATION
=========================================================

FILE NAME: parser.y
SAVE LOCATION: compiler_lab/parser.y

CODE
----
%{
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int yylex(void);
void yyerror(const char *s);

FILE *tac_file;
int temp_count = 0;

char *new_temp(void)
{
    char buffer[32];
    snprintf(buffer, sizeof(buffer), "t%d", ++temp_count);
    return strdup(buffer);
}

void emit(const char *line)
{
    fprintf(tac_file, "%s\n", line);
}
%}

%union {
    char *str;
}

%token WHILE LT ASSIGN PLUS MINUS MUL DIV
%token <str> ID NUMBER
%type <str> expr

%left PLUS MINUS
%left MUL DIV

%%

program
    : while_stmt
    ;

while_stmt
    : WHILE '('
      { emit("L1:"); }
      expr LT expr ')'
      {
          char line[256];
          snprintf(line, sizeof(line),
                   "ifFalse %s < %s goto L2", $4, $6);
          emit(line);
      }
      '{' stmt_list '}'
      {
          emit("goto L1");
          emit("L2:");
      }
    ;

stmt_list
    : stmt_list stmt
    | stmt
    ;

stmt
    : ID ASSIGN expr ';'
      {
          char line[256];
          snprintf(line, sizeof(line), "%s = %s", $1, $3);
          emit(line);
      }
    ;

expr
    : ID
      { $$ = strdup($1); }
    | NUMBER
      { $$ = strdup($1); }
    | expr PLUS expr
      {
          char *t = new_temp();
          char line[256];
          snprintf(line, sizeof(line), "%s = %s + %s", t, $1, $3);
          emit(line);
          $$ = t;
      }
    | expr MINUS expr
      {
          char *t = new_temp();
          char line[256];
          snprintf(line, sizeof(line), "%s = %s - %s", t, $1, $3);
          emit(line);
          $$ = t;
      }
    | expr MUL expr
      {
          char *t = new_temp();
          char line[256];
          snprintf(line, sizeof(line), "%s = %s * %s", t, $1, $3);
          emit(line);
          $$ = t;
      }
    | expr DIV expr
      {
          char *t = new_temp();
          char line[256];
          snprintf(line, sizeof(line), "%s = %s / %s", t, $1, $3);
          emit(line);
          $$ = t;
      }
    ;

%%

void yyerror(const char *s)
{
    fprintf(stderr, "Syntax error: %s\n", s);
}

int main(void)
{
    tac_file = fopen("tac.txt", "w");
    if (tac_file == NULL) {
        perror("Could not create tac.txt");
        return 1;
    }

    int result = yyparse();
    fclose(tac_file);

    if (result == 0) {
        printf("Syntax is valid. TAC generated in tac.txt\n");
        return 0;
    }
    return 1;
}

NOTE ABOUT THIS GRAMMAR
----------------------
The grammar supports the sample assignment and while-loop form in this
question. The loop label is emitted before the condition is parsed, so the
raw TAC places the condition calculation after L1. Part (d) moves that
loop-invariant calculation before L1. Operator precedence makes * and / bind
more tightly than + and -.

PART (d) — OPTIMIZATION USING CODE MOTION
=========================================

FILE NAME: optimizer.c
SAVE LOCATION: compiler_lab/optimizer.c

CODE
----
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

/* Simple exam optimizer:
   1. Moves the condition calculation(s) between L1 and ifFalse to before L1.
   2. Folds integer-only +, -, *, / operations.
   This is intentionally a small teaching optimizer for the sample grammar. */

#define MAX_LINES 500
#define LINE_LEN 256

static int is_label(const char *s)
{
    return (s[0] == 'L' && strchr(s, ':') != NULL);
}

static int constant_fold(char *line)
{
    char lhs[64], a[64], op[8], b[64], extra[8];
    long x, y, result;
    char *eq = strchr(line, '=');
    if (!eq) return 0;

    if (sscanf(eq + 1, " %63s %7s %63s %7s", a, op, b, extra) != 3)
        return 0;

    char *end1, *end2;
    x = strtol(a, &end1, 10);
    y = strtol(b, &end2, 10);
    if (*a == '\0' || *b == '\0' || *end1 != '\0' || *end2 != '\0')
        return 0;

    if (strcmp(op, "+") == 0) result = x + y;
    else if (strcmp(op, "-") == 0) result = x - y;
    else if (strcmp(op, "*") == 0) result = x * y;
    else if (strcmp(op, "/") == 0) {
        if (y == 0) return 0;
        result = x / y;
    } else return 0;

    size_t lhs_len = (size_t)(eq - line);
    if (lhs_len >= sizeof(lhs)) return 0;
    memcpy(lhs, line, lhs_len);
    lhs[lhs_len] = '\0';

    snprintf(line, LINE_LEN, "%s= %ld", lhs, result);
    return 1;
}

int main(void)
{
    FILE *in = fopen("tac.txt", "r");
    if (!in) {
        perror("Could not open tac.txt; run the compiler first");
        return 1;
    }

    char lines[MAX_LINES][LINE_LEN];
    int count = 0;
    while (count < MAX_LINES && fgets(lines[count], LINE_LEN, in)) {
        lines[count][strcspn(lines[count], "\r\n")] = '\0';
        count++;
    }
    fclose(in);

    int label = -1, cond = -1;
    for (int i = 0; i < count; i++) {
        if (strcmp(lines[i], "L1:") == 0) label = i;
        if (strncmp(lines[i], "ifFalse ", 8) == 0) { cond = i; break; }
    }

    /* Move condition calculations from after L1 to before L1. */
    char moved[MAX_LINES][LINE_LEN];
    int moved_count = 0;
    if (label >= 0 && cond > label + 1) {
        for (int i = label + 1; i < cond; i++) {
            if (strchr(lines[i], '=') != NULL) {
                strcpy(moved[moved_count++], lines[i]);
                lines[i][0] = '\0';
            }
        }
    }

    FILE *out = fopen("optimized.txt", "w");
    if (!out) {
        perror("Could not create optimized.txt");
        return 1;
    }

    for (int i = 0; i < count; i++) {
        if (i == label) {
            for (int j = 0; j < moved_count; j++) {
                fprintf(out, "%s\n", moved[j]);
            }
        }

        if (lines[i][0] == '\0') continue;
        constant_fold(lines[i]);
        fprintf(out, "%s\n", lines[i]);
    }

    fclose(out);
    printf("Optimization complete. Optimized TAC saved in optimized.txt\n");
    return 0;
}

EXPLANATION
-----------
Code motion moves a calculation that does not change inside the loop to a
position before the loop label. Here n is not assigned in the loop, so n * 4
can be calculated before L1. Constant folding evaluates expressions made only
of constants, such as 16 * 5 = 80.

The assignment r = t2 stays inside the loop; only the constant multiplication
is folded to t2 = 80. This preserves the behavior if the loop executes zero
times.

PART (e) — TARGET CODE GENERATION
=================================

FILE NAME: codegen.c
SAVE LOCATION: compiler_lab/codegen.c

CODE
----
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

/* Converts the optimized TAC into simple educational pseudo-assembly. */

static int is_number(const char *s)
{
    if (*s == '-' && s[1]) s++;
    if (!*s) return 0;
    while (*s) {
        if (!isdigit((unsigned char)*s)) return 0;
        s++;
    }
    return 1;
}

static void load_value(FILE *out, const char *value)
{
    if (is_number(value))
        fprintf(out, "    LOAD R0, #%s\n", value);
    else
        fprintf(out, "    LOAD R0, %s\n", value);
}

int main(void)
{
    FILE *in = fopen("optimized.txt", "r");
    if (!in) {
        perror("Could not open optimized.txt; run optimizer first");
        return 1;
    }

    FILE *out = fopen("target.txt", "w");
    if (!out) {
        perror("Could not create target.txt");
        fclose(in);
        return 1;
    }

    char line[256];
    while (fgets(line, sizeof(line), in)) {
        line[strcspn(line, "\r\n")] = '\0';
        if (line[0] == '\0') continue;

        if (line[strlen(line)-1] == ':') {
            fprintf(out, "%s\n", line);
            continue;
        }

        if (strncmp(line, "goto ", 5) == 0) {
            fprintf(out, "    JMP %s\n", line + 5);
            continue;
        }

        if (strncmp(line, "ifFalse ", 8) == 0) {
            char left[64], op[8], right[64], word[16], label[64];
            if (sscanf(line, "%15s %63s %7s %63s %15s %63s",
                       word, left, op, right, word, label) == 6) {
                fprintf(out, "    CMP %s, %s\n", left, right);
                fprintf(out, "    JGE %s\n", label);
            } else {
                fprintf(out, "    ; Could not parse condition: %s\n", line);
            }
            continue;
        }

        char lhs[64], rhs[64], a[64], op[8], b[64];
        char *eq = strchr(line, '=');
        if (!eq) {
            fprintf(out, "    ; Unrecognized TAC: %s\n", line);
            continue;
        }

        size_t n = (size_t)(eq - line);
        if (n >= sizeof(lhs)) n = sizeof(lhs) - 1;
        memcpy(lhs, line, n);
        lhs[n] = '\0';
        while (n > 0 && isspace((unsigned char)lhs[n-1])) lhs[--n] = '\0';

        if (sscanf(eq + 1, " %63s %7s %63s", a, op, b) == 3) {
            load_value(out, a);
            if (strcmp(op, "+") == 0) fprintf(out, "    ADD R0, %s\n", b);
            else if (strcmp(op, "-") == 0) fprintf(out, "    SUB R0, %s\n", b);
            else if (strcmp(op, "*") == 0) fprintf(out, "    MUL R0, %s\n", b);
            else if (strcmp(op, "/") == 0) fprintf(out, "    DIV R0, %s\n", b);
            fprintf(out, "    STORE %s, R0\n", lhs);
        } else if (sscanf(eq + 1, " %63s", rhs) == 1) {
            load_value(out, rhs);
            fprintf(out, "    STORE %s, R0\n", lhs);
        }
    }

    fclose(in);
    fclose(out);
    printf("Target code generated in target.txt\n");
    return 0;
}

EXPLANATION
-----------
The backend reads optimized TAC and converts operations into simple pseudo-
assembly instructions:
- LOAD places a value in register R0.
- ADD, SUB, MUL, DIV perform arithmetic.
- STORE writes the result to a variable or temporary.
- CMP compares the loop condition.
- JGE jumps when m >= t1, which is equivalent to the loop condition m < t1
  being false for integer values.
- JMP performs an unconditional jump.
This is educational pseudo-assembly; real instruction names depend on the
target processor.

HOW TO RUN (LINUX / UBUNTU / WSL)
---------------------------------
Open a terminal in the compiler_lab folder.

1. Install the required tools if they are not already installed:
       sudo apt update
       sudo apt install flex bison gcc

2. Generate the parser source and header:
       bison -d parser.y

3. Generate the lexer source:
       flex lex.l

4. Compile the lexer and parser into the compiler executable:
       gcc parser.tab.c lex.yy.c -o compiler

   If your system reports an unresolved yywrap or Flex library error, use:
       gcc parser.tab.c lex.yy.c -o compiler -lfl

5. Run the compiler using the input file:
       ./compiler < input.txt

   Expected terminal message:
       Syntax is valid. TAC generated in tac.txt

6. Compile the optimizer:
       gcc optimizer.c -o optimizer

7. Run the optimizer:
       ./optimizer

   Expected terminal message:
       Optimization complete. Optimized TAC saved in optimized.txt

8. Compile the target-code generator:
       gcc codegen.c -o codegen

9. Run target-code generation:
       ./codegen

   Expected terminal message:
       Target code generated in target.txt

10. View the generated files:
       cat tac.txt
       cat optimized.txt
       cat target.txt

WINDOWS NOTE

EXPECTED OUTPUT FOR PART (a)
----------------------------
LEX recognizes the following tokens in the input:
WHILE, '(', ID(m), LT, ID(n), MUL, NUMBER(4), ')', '{',
ID(r), ASSIGN, NUMBER(16), MUL, NUMBER(5), ';',
ID(s), ASSIGN, ID(x), MUL, ID(y), PLUS, ID(z), ';',
ID(t), ASSIGN, ID(m), PLUS, ID(s), ';', '}'

The lexer passes tokens to YACC; it does not print this list in this implementation.

EXPECTED OUTPUT FOR PART (b)
----------------------------
The parser accepts the supplied program and the terminal displays:

If the syntax is invalid, YACC reports a syntax error.

EXPECTED OUTPUT FOR PART (e): target.txt
----------------------------------------
The file contains pseudo-assembly instructions equivalent to the optimized TAC.
For example, the first lines should be:
    LOAD R0, n
    MUL R0, 4
    STORE t1, R0
L1:
    CMP m, t1
    JGE L2

The rest of the file translates the assignments and arithmetic operations into
LOAD, arithmetic, STORE, JMP, and label instructions. Exact formatting follows
codegen.c.

WHAT TO WRITE IN THE EXAM — SHORT THEORY
----------------------------------------
(a) LEX specification: recognizes keywords, identifiers, constants, operators,
    delimiters, and ignores whitespace.
(b) YACC specification: defines grammar productions for a while loop,
    statement lists, assignments, and arithmetic expressions.
(c) Syntax-directed translation: semantic actions create temporary variables
    and emit TAC instructions.
(d) Code motion: moves loop-invariant calculation n * 4 before L1. Constant
    folding also replaces 16 * 5 with 80.
(e) Target-code generation: translates optimized TAC into pseudo-assembly.
(f) Integration: Flex generates lex.yy.c; Bison generates parser.tab.c and
    parser.tab.h; GCC compiles them; the compiler generates tac.txt; optimizer
    generates optimized.txt; codegen generates target.txt.
